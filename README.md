# Jogo da Cobrinha em C

Sistema desenvolvido em linguagem C para simular o clássico jogo da cobrinha em ambiente de terminal. O projeto permite controlar a movimentação da cobra, coletar alimentos, acumular pontos e registrar recordes, aplicando conceitos fundamentais de programação estruturada e lógica de jogos.

Desenvolvido com foco no aprendizado e na prática de vetores, funções, estruturas condicionais, estruturas de repetição e manipulação de coordenadas. O sistema busca reproduzir a experiência tradicional do jogo da cobrinha por meio de uma interface interativa baseada em texto, utilizando apenas recursos básicos da linguagem C.

## Funcionalidades

* Movimentação da cobra utilizando teclado
* Crescimento da cobra ao consumir alimentos
* Sistema de pontuação
* Registro de recorde durante a execução
* Geração aleatória de comida
* Detecção de colisão com paredes
* Detecção de colisão com o próprio corpo
* Reinício da partida após fim de jogo
* Aumento gradual da velocidade conforme a pontuação
* Interface interativa em terminal
